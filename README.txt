ProofOfWork website

Files:
- index.html: website with Forgot Password and password reset form
- schema.sql: Supabase database setup

Deploy: upload this folder (or its contents) to your static hosting provider.
Supabase setup: Authentication > URL Configuration > add your deployed site URL to Redirect URLs, for example https://comforting-quokka-df7454.netlify.app/**
Then test Forgot password on the deployed website. Email delivery and redirect settings must be configured in Supabase.
